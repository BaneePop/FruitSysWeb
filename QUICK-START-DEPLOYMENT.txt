KORAK 1: Kopiraj fajlove na Windows Server
────────────────────────────────────────────────────────────────────────────────

  Na vašem Mac-u:
  ───────────────
  📦 Fajlovi za kopiranje:
     • FruitSysWeb-Production-v1.2.0-20251222-181217.zip  (39 MB)
     • deploy-to-windows-server-v1.2.0.ps1                (11 KB)

  Kopiraj u Windows Server:
  ─────────────────────────
  C:\Temp\FruitSysWeb-Deployment\

  Metode:
  • USB stick
  • Network share (\\192.168.1.11\C$\Temp\...)
  • Remote Desktop copy-paste
  • FTP/SFTP


KORAK 2: Pokreni Deployment Skriptu
────────────────────────────────────────────────────────────────────────────────

  Na Windows Serveru:
  ───────────────────

  1. Otvori PowerShell kao ADMINISTRATOR
     (Right-click → Run as Administrator)

  2. Navigiraj do foldera:
     cd C:\Temp\FruitSysWeb-Deployment

  3. Pokreni skriptu:
     .\deploy-to-windows-server-v1.2.0.ps1 -IIS -AppPoolName "FruitSysWeb"

  4. Sačekaj ~30 sekundi

  ✅ GOTOVO!


KORAK 3: Testiraj Aplikaciju
────────────────────────────────────────────────────────────────────────────────

  1. Otvori browser:
     http://192.168.1.11:6001

  2. Uloguj se kao admin

  3. Idi na FinansijeHome

  4. Testiraj nove opcije:
     • Pregled Salda
     • Stanje Kase Altiva

  ✅ Ako sve radi - deployment uspešan!

ROLLBACK - Vrati Staru Verziju (2 minute):
──────────────────────────────────────────────────────────────────────────────

  1. Zaustavi aplikaciju:
     Stop-WebAppPool -Name "FruitSysWeb"

  2. Vrati backup:
     $backup = "C:\FruitSysWeb-Backup-YYYYMMDD-HHMMSS"
     Remove-Item -Path "C:\FruitSysWeb\*" -Recurse -Force -Exclude "Logs"
     Copy-Item -Path "$backup\*" -Destination "C:\FruitSysWeb\" -Recurse -Force

  3. Pokreni aplikaciju:
     Start-WebAppPool -Name "FruitSysWeb"

  ✅ Vraćeno na staru verziju!
