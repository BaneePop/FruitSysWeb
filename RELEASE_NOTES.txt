================================================================================
                          POZNATI PROBLEMI
================================================================================

1. Browser Warning: "Unload event listeners are deprecated"
   - Uzrok: Blazor framework koristi zastareli event
   - Impact: Nema (samo upozorenje u konzoli)
   - Status: Biće popravljeno u budućoj verziji Blazor-a

2. Prva učitavanje stranice može trajati 2-3 sekunde
   - Uzrok: Blazor Server inicijalizacija
   - Workaround: Normalno ponašanje, sledeća učitavanja brža

                          UPGRADE SA PRETHODNIH VERZIJA
================================================================================

Ovo je PRVO IZDANJE - nema upgrade procedura.

Za buduće verzije:
1. Backup-ujte trenutni folder
2. Backup-ujte appsettings.Production.json
3. Raspakujte novu verziju
4. Kopirajte stari appsettings.Production.json (proverite nove settings)
5. Restartujte aplikaciju
